CITY-AI
Featured

Multi-camera plate reading & traffic analytics

Reads number plates across several live cameras, stores every sighting in PostgreSQL and maps where each vehicle went.

93.6%exact-match plate reads on a held-out test set

  • PostgreSQL
  • SQL
  • PyTorch
  • YOLO11
  • Redis
  • React
  • Designed the PostgreSQL schema that stores real-time detection events and vehicle tracks from live camera feeds, fed by a Redis event pipeline and queried with SQL for a React GIS dashboard.
  • Trained a CRNN+CTC plate recognizer from scratch on 1,059 annotated crops and 75,000 synthetic plates: 98.8% character accuracy on a leak-free group-split test set.
  • Raised accuracy on degraded frames from 69.1% to 90.4% with confidence-weighted voting across frames of each ByteTrack track.
  • Built a four-tier read system that flags obscured plates with snapshot alerts, and reconstructed routes with OSRM.

SiteSense
Hackathon

A copilot for analysts' company visits

Built with Team Buffer at the Thapar x Japan Hackathon. It helps an analyst prepare for a site visit, record it safely and write up what they found.

3phases: before, during and after the visit

  • FastAPI
  • Python
  • React
  • Tailwind
  • Before: a manager assigns the visit; the analyst uploads financials and gets a checklist of what to look at.
  • During: a phone records short clips while the laptop blurs faces, transcribes speech and deletes the unblurred video within seconds.
  • After: findings compare what was said, what the numbers show and what was seen, then go into a locked, approved PDF report.
